**날짜**: 2026-03-27
**비전**: "다음 달이 아니라 6개월 후를 보여주는 가계부"

# Part 1. 개념

기존 가계부의 한계 극복을 위해 기업회계적 요소를 도입하되, 가계부 고유의 특성을 고려한다.

## 문제 인식

기존 가계부의 근본적 한계: **예측 가능한 것조차 예측 가능하게 보여주지 못한다.**

월급은 매달 정해진 날에 들어오고, 보험료는 매년 같은 달에 나가고, 부조금은 언젠가 반드시 발생한다. 이런 것들은 모두 어느 정도 예측 가능하지만, 기존 가계부는 이를 반영할 구조가 없다. 이 가계부의 모든 설계(목적별 분류, 발생주의, 준비금 등)는 이 문제를 해결하기 위한 것이다.

구체적인 구조적 한계:

1. **소비처 기준 분류, 목적 부재**: "쿠팡 3만원"으로 기록하면 식료품인지 생활용품인지 알 수 없다. 같은 소비처라도 목적이 다를 수 있는데, 기존 가계부는 소비처 단위로만 기록하고 목적별 구분을 하지 못한다. 돈을 "왜" 썼는지를 알아야 패턴을 파악하고 예측할 수 있다.

2. **현금주의 회계**: 연간 보험료 120만원을 1월에 냈다면, 기존 가계부는 "1월에 120만원 지출"로 기록한다. 하지만 실제로는 매월 10만원씩 12개월에 걸쳐 발생하는 비용이다. 현금주의는 특정 월의 수입과 지출을 왜곡하고, 미래 예측을 부정확하게 만든다.

3. **미래 현금흐름 반영 불가**: 예정된 수입(급여, 예금 이자, 보너스)과 예정된 지출(보험료, 자동차 검사) 모두 사전에 알 수 있는 정보인데, 기존 가계부는 이를 미래 계획에 반영할 수단이 없다.

4. **불확실한 지출에 대한 대비 부재**: 부조금, 긴급 수리비 등 시점은 모르지만 반드시 발생할 지출에 대한 대비 수단이 없다. 기존 가계부는 과거 기록에 집중할 뿐, 미래를 보여주지 않는다.

## 핵심 목적

**미래 현금흐름의 정확한 예측**

모든 기능(발생주의 회계, 감가상각, 준비금 계정 등)은 이 하나의 목적을 위한 수단이다.

## 타겟 사용자

재테크/재무관리에 관심 있고, 기초 회계 용어를 이해하거나 배울 의향이 있는 사람. 회계 용어(자산, 부채, 감가상각 등)를 쉬운 말로 포장하지 않고 그대로 사용한다.

## 핵심 개념

### 개념 1: 가계부를 위한 회계 계정 재정의

기업회계의 5대 계정을 가계부 맥락에 맞게 재정의한다.

| 계정           | 정의                                        | 예시                                 |
| -------------- | ------------------------------------------- | ------------------------------------ |
| **자산**       | 보유하고 있으며 화폐가치로 환산 가능한 자원 | 현금, 예금, 투자, 보유물건, 선불비용 |
| **부채**       | 미래에 지급해야 할 의무                     | 카드 미결제, 대출, 미지급금          |
| **순자산**     | 자산 - 부채 (자동 계산)                     | —                                    |
| **수입**       | 해당 월에 귀속되는 경제적 유입              | 급여, 부수입, 투자수익               |
| **지출(비용)** | 해당 월에 귀속되는 경제적 유출              | 식비, 감가상각비, 월할 보험료        |

**핵심 변경**: 기업회계에서 자산은 "미래 경제적 효익(이윤 창출)"을 기준으로 정의된다. 하지만 가계에서 TV는 이윤을 창출하지 않지만 환금가치가 있고 순자산을 구성한다. 따라서 가계부 자산은 **"화폐가치로 환산 가능한 자원"**(환금성/가치 저장)으로 재정의한다.

자산은 **유동자산**(현금, 예금 등 즉시 사용 가능)과 **비유동자산**(부동산, 자동차 등 장기 보유)으로 분리하여, "실제 쓸 수 있는 돈"과 "총 재산"을 구분한다.

### 개념 2: 발생주의 회계

현금이 오간 시점이 아니라, 경제적 사건이 발생한 시점에 기록한다. 회계 기간은 **월 단위**.

| 상황                         | 현금주의 (기존)     | 발생주의 (이 가계부)                      |
| ---------------------------- | ------------------- | ----------------------------------------- |
| 연간 보험료 120만원 1월 납부 | 1월 지출 120만원    | 매월 비용 10만원 × 12개월                 |
| TV 100만원 카드 결제         | 다음달 출금 시 지출 | 구매 시 자산 등록 + 부채(카드미결제) 발생 |
| TV 감가상각 (5년)            | —                   | 매월 자산가치 감소, 비용 발생             |

**자산/비용 구분 기준**: 가계 지출 규모에 비례하는 기준액(materiality threshold)을 설정한다. 기준액 이상의 구매는 자산으로 등록을 권유하고, 미만은 즉시 비용 처리한다. 기업회계에서도 중요성 기준이 기업 규모에 따라 다른 것과 같은 원리.

감가상각은 **정액법**((취득가 - 잔존가액) ÷ 내용연수)으로 단순하게 처리한다. 잔존가액은 기본 0원이되, 중고 매각 예상가 등을 사용자가 입력할 수 있다. 가계부의 목적은 물건의 현재 가치를 대략적으로 아는 것이지, 정밀한 상각이 아니다.

**Rounding 정책**: 나눗셈이 정수로 떨어지지 않을 때, 매월 `floor(총액 / 개월수)`를 적용하고 **마지막 월에 잔여액을 일괄 조정**한다. (예: 100만원/36개월 = 매월 27,777원 × 35개월 + 마지막 월 27,805원). 선불비용 배분에도 동일 정책 적용.

### 개념 3: 내부 복식부기

시스템 내부는 복식부기(거래의 양면 기록)로 동작하되, 사용자에게는 단순한 입력 폼만 보여준다.

복식부기를 도입하는 핵심 목적: **정확한 순자산 추적과 그 변화 예측**. 순자산이 어떻게 변해왔고, 앞으로 어떻게 변할 것인가를 정확히 보여주는 것이 이 가계부의 존재 이유이며, 복식부기는 그를 위한 유일하게 신뢰할 수 있는 방법이다.

부수적 가치:

- **잔액 자동 검증**: 회계등식(자산 = 부채 + 순자산)이 항상 성립 → 입력 오류 자동 발견
- **거래의 양면 추적**: 돈이 어디서 어디로 갔는지 명확

### 개념 3-1: 결제 수단과 거래 유형

복식부기에서 분개를 완성하려면, "어떤 카테고리(비용 계정)"뿐 아니라 "어디서 돈이 나갔는지(자산/부채 계정)"를 알아야 한다. 이를 위해 **결제 수단**을 등록하고, 각 결제 수단은 내부적으로 자산 또는 부채 계정에 연결된다.

| 결제 수단 | 연결 계정 유형  | 거래 시 동작                     |
| --------- | --------------- | -------------------------------- |
| 현금      | 자산-현금       | 즉시 자산 감소                   |
| 은행 예금 | 자산-예금       | 즉시 자산 감소                   |
| 신용카드  | 부채-카드미결제 | 부채 증가 (결제일에 이체로 상환) |
| 체크카드  | 자산-예금       | 즉시 연결 예금 계정 감소         |

거래 유형은 **3가지**: 지출, 수입, 이체.

- **지출**: `Dr. 비용계정(들) / Cr. 결제수단연결계정`
- **수입**: `Dr. 입금계정 / Cr. 수입계정`
- **이체**: `Dr. 입금계정 / Cr. 출금계정` (수입도 지출도 아닌 자산/부채 간 이동. 카드 대금 결제, 계좌 이체 등)

### 개념 4: 현금흐름 예측 체계

**수입과 지출 모두**에 동일한 예측 체계를 적용한다. 가계의 현금 유출입을 4가지로 분류하고, 각각에 맞는 예측 방식을 적용한다.

| 유형            | 성격                  | 수입 예시             | 지출 예시                 | 예측 방식                           |
| --------------- | --------------------- | --------------------- | ------------------------- | ----------------------------------- |
| **고정 반복**   | 금액/주기 확정        | 급여, 예금 이자       | 월세, 구독료, 대출상환    | 사용자 등록 → 자동 반영             |
| **변동 반복**   | 매월 발생, 금액 변동  | 부수입, 프리랜서 수입 | 식비, 교통비              | 지수가중이동평균(EMA) + 이상치 제거 |
| **예정 비반복** | 시점 확정, 비정기     | 보너스, 보험 만기금   | 연간 보험료, 자동차 검사  | 사용자 예정일/금액 등록             |
| **불확실 발생** | 시점/금액 모두 불확실 | —                     | 부조금, 긴급 수리, 의료비 | 준비금 계정                         |

### 개념 5: 준비금 계정

"발생할 것은 확실하지만, 언제 얼마가 필요할지 모르는" 지출에 대비하는 장치.

- **가상 적립**: 실제 돈 이동 없이 회계상으로만 매월 일정액을 적립. 해당 지출 발생 시 준비금에서 차감.
- **보수적 예측 반영**: 준비금 적립액을 미래 현금흐름 예측에서 지출로 반영 → 가용 여유자금이 줄어 보이지만, 예측의 안전마진을 확보.
- **목적별 + 통합 혼합**: 예측 가능한 항목(부조금, 의료비)은 목적별 준비금, 나머지는 통합 비상금.

### 개념 6: 3대 보고서

기업회계의 3대 재무제표에 대응하는 보고서를 제공한다.

| 보고서         | 대응 재무제표    | 핵심 질문                                        |
| -------------- | ---------------- | ------------------------------------------------ |
| **월간 손익**  | 손익계산서 (P&L) | "이번 달 얼마나 벌고 썼나?" (발생주의 비용 기준) |
| **재산 현황**  | 대차대조표 (B/S) | "지금 순자산이 얼마인가?" (유동/비유동 분리)     |
| **현금흐름표** | 현금흐름표 (C/F) | "실제 돈이 얼마나 오고 갔나?"                    |

### 개념 7: 목적별 계정 분류

#### 기업회계와의 차이: 왜 목적별인가

기업회계에서는 비용을 **성격별(by nature)**로 분류하는 것이 기본이다 (원재료비, 인건비, 감가상각비 등). 이유는 외부 감사인과 세무당국이 객관적으로 검증 가능해야 하기 때문이다. 그러나 가계부에서는 이 전제가 성립하지 않는다:

| 기업회계의 성격별 분류 이유 | 가계부에서는?                               |
| --------------------------- | ------------------------------------------- |
| 외부 감사/세무 신고         | 없음                                        |
| 기업 간 표준 비교           | 불필요                                      |
| 다수 분류자의 일관성        | 분류자 = 사용자 본인. 주관적 판단이 곧 정답 |

가계부의 목적은 **미래 현금흐름 예측과 의사결정**이므로, 분류 방식도 이에 최적화되어야 한다.

#### 목적별 분류가 예측에 유리한 이유

1. **의사결정 단위와 일치**: 지출을 줄일 때 "식료품을 줄여야지"가 아니라 "외식 대신 직접 요리하자"처럼 활동/목적 단위로 판단한다. 성격별 분류는 이 단위와 맞지 않는다.
2. **예측 안정성**: 품목 구성은 매월 바뀌어도(손질된 재료 vs 날것+도구) 목적별 총액은 비교적 안정적 → EMA 예측 정확도 향상.
3. **활동의 총비용 가시성**: "요리에 재료+도구+가스비 합쳐서 월 35만원" — 성격별 분류로는 이 합산이 불가능하다.

#### 분류 구조: 계정(목적) > 품목(카테고리)

**계정(상위) = 목적**, **카테고리(하위) = 품목**으로 구성한다.

```
거래: 쿠팡 35,000원
├── [계정: 요리] 카테고리: 식료품-채소  15,000원
├── [계정: 요리] 카테고리: 생활용품-칼  12,000원
└── [계정: 청소] 카테고리: 생활용품-세제  8,000원
```

같은 "생활용품"이라도 요리 목적이면 요리 계정, 청소 목적이면 청소 계정으로 분류된다.

#### 목적별 분류의 약점과 대응

- **입력 시 인지 부하**: 품목 분류보다 판단이 필요함 → AI가 목적까지 추론하여 제안, 과거 패턴 기반 자동 매핑으로 완화
- **다목적 물건의 애매함**: "미네랄워터가 요리용인가 생활용인가?" → 사용자가 최종 판단 (본인의 주관이 곧 정답)
- **외부 벤치마크 비교 불가**: 일반 가계부 통계는 품목 기준 → MVP에서는 미지원, 필요 시 품목 태그 병행으로 대응 가능

# Part 2. MVP 구현사항

## 인증

- Google 소셜 로그인 (Supabase Auth)

## 온보딩

- 월 소득/월 지출 범위 입력 (자산/비용 구분 기준액 산정용)
- 결제 수단 등록 (현금, 은행 예금, 신용카드 등 — 최소 1개 필수)
- 기본 카테고리 템플릿 자동 생성
- AI API 키 입력 (선택, 이미지 인식 기능 사용 시)

## 거래 입력

- **3가지 거래 유형**: 지출, 수입, 이체
- **지출**: 날짜, 항목명, 금액, 카테고리, **결제수단** 선택. 한 건의 결제를 여러 항목으로 분리 입력 가능 (top-down: 총액 입력 후 분배).
- **수입**: 날짜, 수입 카테고리, 금액, **입금 계정** 선택.
- **이체**: 날짜, 출금 계정 → 입금 계정, 금액. (카드 대금 결제, 계좌 이체 등)
- **이미지 업로드**: 영수증/결제내역 이미지 → 멀티모달 AI API로 파싱 → 항목/금액/카테고리 자동 추출 → 사용자 확인/수정 후 저장. API 비용은 사용자 본인 키 사용.
- **자산 등록 유도**: 기준액 이상 구매 시 "자산으로 등록할까요?" 제안 → 내용연수 입력 → 자동 감가상각
- **거래 목록**: 기간별/카테고리별/거래유형별/금액 범위 필터 + 텍스트 검색

## 반복/예정 거래 등록

- 고정 반복 (월세, 구독료 등): 금액/주기/시작일 등록 → 매월 자동 생성
- 예정 비반복 (연간 보험료 등): 예정일/금액 등록 → 해당 월 반영
- 선불비용 자동 배분: 연간 납부 항목은 월할 비용으로 자동 배분

## 준비금 관리

- 준비금 계정 생성 (목적별 / 통합 비상금)
- 월 적립액 설정
- 해당 지출 발생 시 준비금에서 차감

## 대시보드 (메인 화면)

- **이번 달 요약** (비용 관점): 수입, 비용(발생주의), 순저축/순소비
- **미래 예측 그래프**: 월별 예상 잔액 (6개월/12개월 전환 가능), 단일 예측선
- **순자산 추이**: 순자산 시계열 변화 그래프
- 두 영역(이번 달 요약 + 예측 그래프)을 동등하게 배치
